## 打开模型设置

1. 打开底栏“应用”。
2. 在应用网格里点“模型设置”。
3. 在详情页点“打开”。
4. 按“模型设置”网页显示的步骤完成模型设置。

模型设置是一个应用网页，不是“设置”里的原生页面。配置一次后，使用模型网关的 Agent 和应用共用这份配置。

## 打不开模型设置

- 如果应用网页打不开，先打开“应用” → “连接”，查看“状态”。状态是“连接中”时等待连接；显示断开原因时按“连接”页的下一步处理。
- 如果弹窗显示“打不开”以及“还没有连上家里的服务器：…”：先恢复连接，再回到“模型设置”点“打开”。
- 如果模型设置网页提示“模型网关没在运行”，等待“模型设置”应用就绪后重试；仍然失败时重新打开网页。

Wonton App 只负责打开“模型设置”网页，网页里的控件和提示由该应用提供；不要把 API 密钥粘贴到聊天或其他应用中。
