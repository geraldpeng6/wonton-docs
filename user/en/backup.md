---
title: Back up chat history
summary: Save a recovery key so a new device can retrieve earlier messages
---

## Turn on backup

1. Open “设置” (Settings) in the bottom bar.
2. Tap “聊天记录备份” (Chat backup).
3. Check that the page says “还没有备份聊天记录” (Chat history is not backed up).
4. Tap “开启备份” (Enable backup).
5. When “保存恢复密钥” (Save recovery key) appears, store the key in a password manager or another safe place. It is shown only once.
6. Tap “复制” (Copy) if needed. After you have stored it safely, tap “已保存” (Saved). The device no longer keeps this displayed key after that.

If this device is not verified, the page says “要到最早配对的那台设备上开启” (Enable it on the first device that was paired). Complete the setup on that first paired device.

## Retrieve messages on a new device

After pairing the new device, open “设置” → “聊天记录备份”. If the page says “这台设备还看不到以前的消息” (This device cannot see earlier messages), paste the saved key into “恢复密钥” (Recovery key) and tap “取回以前的消息” (Retrieve earlier messages). The button stays disabled while the field is empty.

The page shows “正在处理…” (Processing…) while it works. Return to the chat list when it completes.

## Status and errors

- “聊天记录已备份” (Chat history backed up): backup is enabled; use the recovery key when changing phones or adding a device.
- “恢复密钥还没保存” (The recovery key has not been saved): save the one-time key first, then tap “已保存”.
- “需要恢复密钥” (Recovery key required): enter the key on the backup page.
- “还不知道备份的情况” (Backup status is unknown) or “连上家里的服务器后才能确认” (Connect to the home server to check): restore the connection first.
- A dialog titled “操作被拒绝” (Operation rejected): the core rejected the action. Follow the reason in the dialog; never send the recovery key in chat.
- A dialog titled “操作失败” (Operation failed): background processing failed. Follow the reason; if the result is uncertain, reopen the backup page and check the status.
