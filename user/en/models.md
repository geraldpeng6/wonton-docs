## Open Models

1. Open the “应用” (Apps) tab.
2. Tap “Models” in the app grid.
3. Tap “打开” (Open) on its detail page.
4. In the Models web app, follow its displayed steps to complete the model setup.

Models is an app web page, not a native screen under “设置” (Settings). Wonton only opens the page; its controls and messages come from that app.

## If Models does not open

- Open “应用” → “连接” (Connection) and check “状态” (Status). Wait if it says “连接中” (Connecting); if it shows a disconnection reason, follow the next step on the Connection page.
- If the dialog says “打不开” (Cannot open) and “还没有连上家里的服务器：…” (Not connected to the home server: …), restore the connection, then tap “打开” again.
- If the Models page says “模型网关没在运行” (The model gateway is not running), wait for the Models app to become ready and try again. If it still fails, reopen the page.

The model-configuration entry is the “Models” web app in the Apps grid. Do not paste an API key into chat or another app.
