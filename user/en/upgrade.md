---
title: Update apps
summary: Review version changes and permissions before updating an installed app
---

## Update from the App Store

1. Open the “应用” (Apps) tab.
2. Tap “应用商店” (App Store). An installed app with an older version shows “更新” (Update).
3. Tap “更新”.
4. On the “升级” (Update) page, check the version change, source, release notes, permissions, and requirements.
5. Tap “升级” (Update) to confirm.

## Update from app details

Tap the app icon on the Apps tab, or open the app from the App Store. When “更新” appears beside the title, tap it, review the “升级” page, and tap “升级”.

While the update runs, the task says “正在升级” (Updating). On success it says “已升级” (Updated), and the detail page reloads. Do not keep tapping the button while the task is running.

## If the task fails

- “应用在确认之后变了，请重新查看、确认。” (The app changed after confirmation; review and confirm again.): tap “重新查看” (Review), check the version, permissions, and notices again, then confirm.
- “家里的服务器正在升级，升级结束后再试。” (The home server is updating; try again when it finishes.): wait for the server update to finish.
- “家里的服务器出了错，稍后再试。” (The home server returned an error; try again later.): retry later.
- “App 和家里的服务器版本对不上，请更新 App 或家里的服务器。” (The app and server versions do not match; update one or both.): update the app and server.
- “结果不确定：…” (Result uncertain: …): refresh the Apps page, check the actual version, and then decide whether to retry.

Server-core upgrades require core ≥ 0.9.0. Use the upgrade procedure supplied for the server installation; the app’s “升级” button updates apps, not the server core.
